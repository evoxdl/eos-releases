Please welcome /e/OS 2.2! :rocket:

We are proud to deliver the /e/OS 2.2. Enjoy all the new features and improvements it embeds!

## ✨ We embedded some improvements! 

:children_crossing: Parental Control

- This new feature has been implemented to help you protect your children online. Learn more at https://doc.e.foundation/support-topics/parental-control

:shield: **Advanced Privacy**

- To help you protect even more your privacy, the app is now blocking 800 new trackers


:shopping_bags: **App Lounge**

- The Non Safe For Work (NSFW) rating by F-Droid is now available in App Lounge so you can install these apps knowingly


:date: **Calendar** 

- You'll now be able to personalize the color of an event if you wish so


:iphone: **Samsung S7 & S7 Edge** have been upgraded to Android 12 :tada: 

:iphone: **Fairphone 4**

- You'll now be able to enjoy Fairphone's default camera app to take pictures if you want to, you just need to enable one setting and reboot your phone. Warning though, for now the video mode does not work, it'll be fixed in a next release.
- The 48MP/50MPx mode has been added into /e/OS Camera for this phone

:iphone: **Fairphone 5**

- The 48MP/50MPx mode has been added into /e/OS Camera for this phone



🦸 **Third Party Apps support**
 - It's now possible to share Snapshot's location in Signal
 - Third party apps are now using the AppLounge account for the Licensing feature

:calling: **Updater**

- An option is now available to "See all available updates" instead of only the next one
