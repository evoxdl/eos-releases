Please welcome /e/OS 3.1.1! :rocket:

We are proud to deliver the /e/OS 3.1.1 version for supported devices whether they are on an Official or a Community build.\
Enjoy all the new features and improvements it embeds!

## ✨ We embedded some improvements! 

:iphone: **The Fairphone (Gen. 6)**

- Mobile Data & VoLTE are now enabled by default whereas VoWiFi is disabled by default
- /e/OS Camera allows pictures of 50 MP
- /e/OS can now be installed on The Fairphone (Gen. 6) through the /e/OS Installer

:placard: Live caption

- Caption text can now be repositioned

:busts_in_silhouette: **Parental Control**

- A warning has been added to inform parents they need to carefully save the security code they define as there is no mean to get it back if they forget it.

🦸 **Third Party Apps support**

- The Fairphone (Gen .6) now benefits from an improved compatibility with third party apps.

## 🕙 Software updates
 
➕ **LineageOS 22.2** latest bug fixes and security updates have been merged ([list](https://review.lineageos.org/q/branch:lineage-22.2+status:merged+after:%222025-04-07+19:00:00+%252B0100%22+before:%222025-07-14+06:44:00+%252B0100%22))

➕ **Browser** has been updated to upstream [v138.0.7204.179](https://github.com/uazo/cromite/releases/tag/v138.0.7204.184-0509d052981e047d6670967788a3e916c70fd4b9). Please note we did not use v138.0.7204.184 from Cromite because it is a Windows-specific release. v138.0.7204.179 is for Android and include the same Cromite patches as in v138.0.7204.184.

➕ **microG** has been updated to upstream [v0.3.8.250932](https://github.com/microg/GmsCore/releases/tag/v0.3.8.250932)

## 🐛 Bug fixes

:shield: **Advanced Privacy**

- Fake location is now instant which prevents unallowed apps to ever access the real location

:shopping_bags: **App Lounge**

- App Lounge now only opens F-Droid link pointing to an application

📅 **Calendar**

- Signature of the Calendar app is fixed so App Lounge does not offer an incompatible update for it.

:iphone: **The Fairphone (Gen. 6)**

- Video recording sound has been improved in /e/OS Camera
- Digital Zoom has been fixed in /e/OS Camera
- WPA3 Hotspot has been fixed

⛳ **Find my Device**

- Characters composing the code are now horizontally centered in their box whatever the resolution and font size

:mage_medium_skin_tone: **First Time Set-up Wizard**

- The Protect your device screen is now displayed properly on tablets
- The `Skip` button is no longer greyed out on the `Set up Find my Device` and `Set up Parental Control` screens when the device is rotated

:keyboard: **Keyboard**

- The regression on the globe key introduced with Murena Voice to Text is now solved

:sunrise: **Launcher**

- Navbar is no longer floating inside Camera's UI
- Homescreen apps are no longer missing on first boot
- Alignment of the 3 navigation buttons has been improved on tablets
- Taskbar can now be used along 3 button navigation on tablets
- App folder is now displayed properly in any situation

:placard: **Live caption**

- Language download dialog no longer disappears when rotating the screen

:busts_in_silhouette: **Parental Control**

- Screen time is now handled properly in every configuration

:gear: **Settings**

- On tablets in landscape mode, the list of entries is now displayed from the top

🦸 **Third Party Apps support**

- Revolut, Yuh, web.de, GMX and Yuka now work on /e/OS

## ⚠ Security fixes

This /e/OS 3.1.1 version includes the [Android security patches](https://source.android.com/docs/security/bulletin/2025-08-01) available as of August, 1st 2025.
