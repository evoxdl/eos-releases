Please welcome /e/OS 2.1! :rocket:

We are proud to deliver the /e/OS 2.1. Enjoy all the new features and improvements it embeds!

## ✨ We embedded some improvements! 


:shopping_bags: **App Lounge**
- Content rating (PEGI score, etc..) is now displayed in the app description


:date: **Calendar** 
- It's now possible to switch calendar for an existing event


:camera: **Camera**
- It's now possible to enable the 48MP/50MPx resolution for Fairphone 4 and Fairphone 5


:iphone: **Fairphone 4** has been upgraded to Android 13 :tada: 


:iphone: **Murena 2**
- Lift to wake settings is now disabled by default


:sunrise: **Launcher**
- eDrive's widget preview is now available 

🦸 **Third Party Apps support**
- We now provide our own backend location services to take over Mozilla Location Services ending on June 12th



## 🕙 Software updates
 
➕ **LineageOS 20** latest bug fixes and security updates have been merged ([list](https://review.lineageos.org/q/branch:lineage-20.0+status:merged+after:%222024-04-24+19:00:00+%252B0100%22+before:%222024-05-27+09:00:00+%252B0100%22))

➕ **FP4's firmware** is now updated to TP2D

## 🐛 Bug fixes


:man_in_tuxedo_tone3: **Account Manager**
- Logging out right after logging in is now handled properly


:shopping_bags: **App Lounge**
- The results are now always displayed from the top 

:camera: **Camera**
- QR scanning is now possible from quick settings
- Scanning barcodes no longer provokes a crash of the app

:iphone: **Fairphone 4**
- The microphone's performance in Jitsi calls with speakerphone is now the expected one.

:iphone: **Fairphone 5**
- Thermal HAL now starts properly
- Native executables for Cortex-A76 CPU are now optimized
- There are no more random crashes to bootanimation which send back to lockscreen



:sunrise: **Launcher**
- Apps are prevented from adding widgets on any screen but the widget panel as long as the feature is not supported
- Touch on screen is now systematically taken into account


## ⚠ Security fixes

This /e/OS v2.1 version includes the [Android security patches](https://source.android.com/docs/security/bulletin/2024-05-01) available as of [May] 2024.
