Please welcome /e/OS 3.3! 🚀

We are proud to deliver the /e/OS 3.3 version for supported devices whether they are on an Official or a Community build.
Enjoy all the new features and improvements it embeds!

## ✨ We embedded some improvements!

👤 **Account Manager**

- Logging into Murena Workspace in Account Manager now supports OpenID Connect for new and current /e/OS users. As a current user, you'll get a notification to help you migrate to OpenID Connect
- When users change their Murena Workspace password, they are now prompted to enter their new password in Account Manager instead of seeing errors

🛡️ **Advanced Privacy**

- Permanent notifications to inform on real time tracking and released with /e/OS 3.2 have been removed as we received negative feedback on this feature

🛍️ **App Lounge**

- Apps without ratings now display `N/A` (Not Available) instead of a `0`
- App search results now display up to 3 open-source apps by default to help the most relevant options appear first. If you’d like to explore more, you can use the 'Open Source' or 'PWA' filter buttons to see all available open-source apps or PWAs for your search.

:1234: **Calculator**

- User Interface in large text / display size has been improved

📱 **The Fairphone (Gen. 6)**

- Radio buttons are now used instead of switches for selecting switch customization actions
- Cellular network are now listed in a user friendly way

🏠 **Launcher**

- Added a default shortcut to Murena Workspace on the launcher as a webview app so you can access easily the Murena Workspace's features directly from your device

📝 **Live Caption**

- Updated the Live Caption feature with support for Kyrgyz language (Kyrgyzstan).

:information_source: **Notifications**

- Notifications regarding /e/OS and Murena Workspace features and maintenance will now reach you directly on your device

🦸 **Third Party Apps support**

- Android Auto now works on AOSP 15 devices 🎉 Please refer to [the documentation](https://doc.e.foundation/support-topics/android-auto) to know more.

## 🐛 Bug fixes

🛍️ **App Lounge**

- App Lounge now works properly with Ethernet connections
- The text of the button in the `Updates` tab is now always correct
- Geo or age-restricted apps are now displayed as not available instead of opening a webview inside App Lounge
- Fixed blinking issues in the App Lounge interface

🛡️ **Advanced Privacy**

- Fixed inconsistencies between formal and informal French in the weekly report
- Fixed Advanced Privacy's weekly report notifications popping continuously on first day of Winter time

📱 **Fairphone 5**

- Fixed the issue where Red by SFR was choosing the wrong APN, causing no data connectivity
- App Lounge can now show and install all the common apps for this device

📱 **The Fairphone (Gen. 6)**

- The switch's position is now respected after a reboot
- Added missing translations for the FP6 switch customization menu
- Rollback date is now aligned with Fairphone's

💌 **Mail**

- Fixed the broken PDF reader share function

🚸 **Parental Control**

- Fixed UI issues in Parental Control including making it more responsive across different screen sizes
- Apps no longer remain locked after an OS update, even after a new day starts
- Apps outside the child’s age group are now toggled off by default in the installed app management screen.

⚙️ **Settings**

- Fixed warnings about PicoTTS being built for an older Android version.
- APNs updated for SFR MVNOs like RED, Prixtel, Reglo, etc. to have calls, SMS, MMS and data work as expected

🦸 **Third Party Apps support**

- Fixed security issues detected by the MAIF app on /e/OS
- Fixed the emulator error on Grindr
- DSK Mobile app no longer crashes
- Some crashes when updating microG from old version of /e/OS were fixed

## ⚠️ Security fixes

This /e/OS 3.3 version includes all Android security patches available as of [December, 1st](https://source.android.com/docs/security/bulletin/2025-12-01).
