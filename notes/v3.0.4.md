Please welcome /e/OS 3.0.4! :rocket:

We are proud to deliver the /e/OS 3.0.4 version for supported devices whether they are on an Official or a Community build.

This release is focused on security. For the Community devices which did not get [/e/OS 3.0.2](https://gitlab.e.foundation/e/os/releases/-/releases/v3.0.2-a15) it also releases accessibility features like Live Caption. 

## 🕙 Software updates
 
➕ **Browser** has been updated with upstream version [138.0.7204.97](https://github.com/uazo/cromite/releases/tag/v138.0.7204.97-418943de425329115e0783375c12ee5aec36e2b6). This version fixes two 0-day exploits:
   - https://nvd.nist.gov/vuln/detail/CVE-2025-5419
   - https://nvd.nist.gov/vuln/detail/CVE-2025-6554

 ## ⚠ Security fixes

This /e/OS 3.0.4 version includes the [Android security patches](https://source.android.com/docs/security/bulletin/2025-06-01) available as of June 2025.
