Please welcome /e/OS 3.1.4! :rocket:

We are proud to deliver the /e/OS 3.1.4 version for supported devices whether they are on an Official or a Community build.

## 🕙 Software updates
 
➕ **Browser** was updated to upstream [v140.0.7339.51](https://github.com/uazo/cromite/releases/tag/v140.0.7339.81-edd60fee151cd499edd5b7522c4be832b4e3499d). Please note we did not use v140.0.7339.81 from Cromite because it is a Windows-specific release. v140.0.7339.51 is for Android and includes the same Cromite patches as v140.0.7339.81.

## 🐛 Bug fixes

:shopping_bags: **App Lounge**

- The user experience regarding the choice between Anonymous and Google sign-ins has been improved
- By default the update check interval is now set to **weekly** instead of **daily** so Play Store APIs are less frequently used.

:iphone: **Fairphone (Gen. 6)**
- The unnecessary reboots happening with 3.1.3 in North America have been fixed and the device now passes FCC certification. 
 
:mag_right: **[Murena Find](https://murena.qwant.com)**

- The Fully qualified Domain Name (FDN) error is fixed.

## ⚠ Security fixes

This /e/OS 3.1.4 version includes the [Android security patches](https://source.android.com/docs/security/bulletin/2025-09-01) available as of September, 1st 2025.
