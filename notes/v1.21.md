Please welcome /e/OS 1.21! :rocket:

We are proud to deliver the /e/OS 1.21. Enjoy all the new features and improvements it embeds!

## ✨ We embedded some improvements! 

:camera: **Camera**
- The option to force the screen display to maximum brightness while using the Camera has been disabled by default to prevent battery drain

:iphone: **Fairphone 3** is now running Android 13 :tada: 




:telephone_receiver: **Dialer**
- Dialpad text is now perfectly readable in both light and dark mode.


:books: **Documentation**
- IMG package support for SHIFT 6mq has been added. It is now possible to lock the bootloader with the SHIFT 6mq.


:speech_balloon: **Message**
- the auto-compress option for MMS' attachments has been set to _Automatic (uses allowed carrier max size)_ by default so picture quality is better.



:tools: **Recovery**
- The user can now reboot their phone right away after an installation from the Recovery instead of being asked whether they want to install additional packages 

:gear: **Settings**
- there is now a dedicated section for /e/OS specific options in the Developer options.
- when Voice over LTE option is available to make a call, an icon appears in the status bar



🦸 **Third Party Apps support**
- The option "Remember from GPS" is now activated by default in microG to fetch quicker some already visited locations.
