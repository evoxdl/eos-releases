Please welcome /e/OS 3.2! :rocket:

We are proud to deliver /e/OS version 3.2 for all supported devices, whether they are on an Official or Community build.\
Enjoy all the new features and improvements it embeds!

## ✨ We embedded some improvements! 

:shield: **Advanced Privacy**

- You are now informed in real time of application which are leaking/trying to leak your data. If you don't want to be notified of this you can simply long press the notification, tap on the cogwheel and untoggle the notification.

:shopping_bags: **App Lounge**

- App size is now also displayed for applications coming from F-Droid
- It displays common apps based on region and not on locale

:iphone: **The Fairphone (Gen. 6)**

- Switch customization is now available!
- Fairphone Camera app is now available on /e/OS!
- Battery charge limit is now available in Settings

:iphone: **Fairphone 5** is now available on AOSP 15 whether the phone was on AOSP 13 or AOSP 14 before! :tada:

:iphone: **Google Pixel 8** is now available on AOSP 15 :tada:

:iphone: **Google Pixel 7** is now available on AOSP 15 :tada:

## 🐛 Bug fixes

:shield: **Advanced Privacy**

- The button allowing the user to see more details in Advanced Privacy's weekly report is now working

:shopping_bags: **App Lounge**

- The Search feature is now working more smoothly
- Opening a Play Store link while using App Lounge in "Open Source and PWA only" mode is now handled properly
- The weekly update check option now maintains a correct interval for checking apps' update
- App Lounge now redirects the user to the home page when a link to an application is not available

:iphone: **The Fairphone (Gen. 6)**

- Wired headphones now properly work for both music and phone calls

:iphone: **Fairphone 5**

- Display refresh rate now always stays at 90hz so there is no graphical errors in the boot animation

:children_crossing: **Parental Control**

- The crash which could be observed from time to time is no longer happening which makes screen time management always reliable

:gear: **Settings**

- The blank space in `Settings` > `Storage` has been removed to prevent it from launching Smart Cleanup

🦸 **Third Party Apps support**

- Logging into Garmin Connect app is now possible again
- Deeplink activation is now automatically handled

## ⚠ Security fixes

This /e/OS 3.2 version includes the [Android security patches](https://source.android.com/docs/security/bulletin/2025-10-01) available as of October, 1st 2025.
