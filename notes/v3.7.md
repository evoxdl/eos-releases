## 🐛 Bug fixes

:shopping_bags: **App Lounge**

- Fixed an issue with ratings in Search screen where apps would incorrectly show a "0.0" user rating instead of "N/A".
- F-Droid app links are now handled properly.
- Fixed some text casing and naming inconsistencies across tabs and options for a more polished UI layout.

:rocket: **Launcher**

- Fixed search behavior where pressing Enter on the keyboard added a new line instead of executing the app search.

:musical_note: **Music** 

- App has been updated to fix some theming related issues.

:speech_balloon: **Voice to Text**

- Fixed a visual glitch where the Speech-to-Text interface would incorrectly overlap and appear underneath the system navigation bar.

## ⚠ Security fixes

This /e/OS 3.7 version includes all Android security patches available as of [April 2026](https://source.android.com/docs/security/bulletin/2026/2026-04-01).
