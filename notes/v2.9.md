Please welcome /e/OS 2.9! :rocket:

We are proud to deliver the /e/OS 2.9 version for supported devices whether they are on an Official or a Community build.\
Enjoy all the new features and improvements it embeds!

## ✨ We embedded some improvements! 

:iphone: **Google Pixel 8** is now available on AOSP 14 for Community builds

:pencil: **Notes**

- it's now possible to export your Notes to a `.md` file on your device

:children_crossing: **Parental Control**

- [Mullvad DNS All](https://all.dns.mullvad.net/dns-query) has been implemented as Parental Control's default DNS and [Kids DNS0](https://www.dns0.eu/kids) is implemented as a fallback.

🦸 **Third Party Apps support**

- location is now requested from supported Hotspot by default, so now you can be located while connected to the train's Wi-Fi for instance

## 🕙 Software updates

➕ **LineageOS 21** latest bug fixes and security updates have been merged ([list](https://review.lineageos.org/q/branch:lineage-21.0+status:merged+after:%222024-01-29+19:00:00+%252B0100%22+before:%222025-03-12+06:44:00+%252B0100%22))

➕ **Browser** has been updaded to upstream version [v134.0.6998.89](https://github.com/uazo/cromite/releases/tag/v134.0.6998.89-f13b33b73e22ecaa1ae9a567a8e0c74caf446678)

➕ **Web Calendar Manager** has been updaded to upstream version [v2.2.6](https://github.com/bitfireAT/icsx5/releases/tag/v2.2.6)

## 🐛 Bug fixes

:man_in_tuxedo_tone3: **Account Manager**

- Web Calendar Manager no longer crashes while editing an already added entry 


:shopping_bags: **App Lounge**

- icon display for PWA and Open Source apps has been fixed
- common apps are not visible anymore when disabled in the settings and are displayed systematically among searched results when enabled in the settings
- F-Droid and Google Play Store links open in App Lounge
- the Privacy Score has been removed from the search and category views as it was impacting Exodus too much
- in Open Source and PWA mode it's possible to display apps' detail page
- all pending updates for Open Source apps are now taken into account

:iphone: **Google Pixel Tablet**

- dock does not vanish from the launcher anymore

🔄 **File Synchronization**

- sync in loop has been fixed when quota was reached

:sunrise: **Launcher**

- dock background's blur effect has been removed as it was creating a bad UX on some devices

:love_letter: **Mail**

- user's password is now updated in Mail when the user updates it in Account Manager

:pencil: **Notes**

- the local mode can now be initialized without a connection or during a service outage

:gear: **Settings**

- APN has been fixed for T-Mobile so calls, SMS, MMS and data work as expected

## ⚠ Security fixes

This /e/OS 2.9 version includes the [Android security patches](https://source.android.com/docs/security/bulletin/) available as of March 2025.
