Please welcome **/e/OS 4.0**! :rocket:

We are proud to deliver the /e/OS 4.0 version for supported devices whether they are on an Official or a Community build.
Enjoy all the new features and improvements it embeds!

## ✨ We embedded some new features and improvements!

:iphone: **Gigaset GS6/GS6 Pro** is now officially available with /e/OS :tada: 

:iphone: **OnePlus Nord** is now available on AOSP 16 :tada: 

- The issue where Wi-Fi and Mobile Data connections could remain unavailable after a system update is now fixed.

:shopping_bags: **App Lounge**

- App download and installation flow improved with better error handling and code organization.
- Support for shared libraries added during application installations.
- Chrome is now supported on /e/OS and has been removed from the blacklisted app list.

:globe_with_meridians: **Browser**

- Autofill functionality is now enabled by default to seamlessly integrate with a password manager.

:1234: **Calculator**

- Adjusted the interface design to properly accommodate the new `Clear` button.
- Calculator now has a new icon

:sunrise: **BlissLauncher**

- Introduced a new set of brand new wallpapers and a couple of new icons!

🦸 **Third Party Apps support**

- Apps that support GMS-free devices can now run on /e/OS thanks to a new option to hide microG from selected third-party apps. This should help apps like Swisscard and BoursoBank.

## 🐛 Bug fixes

:shopping_bags: **App Lounge**

- Fixed an issue with the "Update all" button failing if the screen changed during the process.
- App updates no longer get stuck or skipped when many updates are available simultaneously.
- Fixed a bug where App Lounge would sometimes reinstall an old version of an app instead of the latest one.
- Fixed an issue preventing the MicroG re-login process from working properly.
- Fixed the Updates list auto-scrolling to the top during an update.

👤 **Account Manager**

- Fixed an issue where Murena Workspace would sometimes get logged out after the initial login.

:clock8: **Clock**

- Fixed the Clock app icons displaying the wrong color in the system notification panel.

:camera: **Camera**

- Fixed a bug on some devices where switching between front and back cameras would cycle through the wrong lenses.


## ⚠ Security fixes

This /e/OS 4.0 version includes all Android security patches available as of [June 1st, 2026](https://source.android.com/docs/security/bulletin/2026/2026-06-01).
