Please note: /e/OS 3.1.2 has been superseded by version 3.1.3

We had prematurely released builds for version 3.1.2 intended for The Fairphone (Gen. 6) on the Official channel. This version was meant to introduce important FCC certification, making the device fully usable in the USA.

Unfortunately, this premature release contained critical unresolved issues:
- IMEI was incorrect preventing SIM cards from connecting to mobile networks in the affected region.
- The FCC certification changes were broken & The Fairphone (Gen 6)'s slider functionality was also non-operational.

To resolve this, we have withdrawn the 3.1.2 build and replaced it with a new, corrected version: /e/OS 3.1.3.

We strongly recommend all users to install the 3.1.3 update, which properly includes the functional FCC certification and fixes for the network and slider issues. Please check your device's updater to get the latest version.

We sincerely apologize for this oversight and any inconvenience caused. Thank you for your understanding and continued support.
